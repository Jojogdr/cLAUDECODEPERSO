# cc0/ — whooshes and ticks

Source: https://github.com/novincode/atomcut-library (packs `motion-essentials` and `impacts-risers`),
licence CC0-1.0 as declared in each pack's `pack.json` (sounds synthesised from DSP). Converted to 48 kHz / 16-bit stereo.

Kept only bright, bass-free files (spectral centroid 5.9–9 kHz, < 10 % energy under 200 Hz) to respect the client's
rule: short, high interface sounds, no useless bass. Use them for transitions (the client bank has no real whooshes).

| file | length | use |
|---|---|---|
| whoosh-tight | 0.19 s | quick cut, card snap |
| whoosh-pass-fast | 0.31 s | GL transition, whip |
| whoosh-high | 0.36 s | light transition, text fly |
| riser-snap | 0.55 s | short build into a hit |
| transition-sweep | 0.65 s | slide / page transition |
| whoosh-reverse | 0.73 s | pull-in before a reveal (align `end` on the cut) |
| whoosh-pass-slow | 0.93 s | slow push, end card |
| type-tick | 0.06 s | typing rows, counters |
